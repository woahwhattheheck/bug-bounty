# bounty-work

Engineering handoffs for open-source bounties (>= $15, payout-on-merge maintainers, on platforms green for receiving).
Each subdirectory `<owner>__<repo>__<issue>/` holds `fix.patch` (apply with `git am`) and `HANDOFF.md`
(bounty details, validation evidence, and a ready-to-paste PR title/body with the claim line).
Submission upstream is done by the account owner from these handoffs.
